# AutoLog – vehicle log (Drivvo-style)
Offline Android app: History, Reminders, Service, Income, Expense, Refueling, Reports.

## Get the APK
1. Create a new GitHub repo and upload all files of this folder (keep `.github/workflows`).
2. Open the **Actions** tab -> **Build APK** (runs automatically on push, or press *Run workflow*).
3. When it turns green, open the run -> **Artifacts** -> download `AutoLog-apk`, unzip, install `app-debug.apk` on your phone (allow "install unknown apps").

Data is stored on the phone (localStorage). Use Reports > Backup to copy/restore your data.
